# S3 Presigned URL Starter Backend

This is a simple Express.js boilerplate for generating AWS S3 **presigned URLs** using the AWS SDK v3.  
It serves as a clean starting point for projects that involve uploading files to S3 from the frontend securely.

---

## 🚀 Features

- Basic Express server setup
- CORS enabled
- Environment variable support using `dotenv`
- Modular route handling

---
## 🛠️ Setup Instructions

1. **Clone the repo**
   ```bash
   git clone https://github.com/your-username/s3-presigned-url-starter.git
   cd s3-presigned-url-starter

2. **Install Packages**
   ```bash
   npm install

3. **Build the project and run**
   ```bash
   tsc -b
   node dist\index.js
